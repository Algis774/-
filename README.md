# Фонарь — Android-приложение

Одноэкранное приложение: большая кнопка включает/выключает вспышку телефона. При включении произносится фраза «Ебать ты петух» через системный синтез речи Android.

## Сборка APK

1. Установите Android Studio (актуальную версию) и Android SDK Platform 35.
2. Распакуйте архив и откройте папку `FonarApp` в Android Studio.
3. Дождитесь завершения Gradle Sync.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Установка

Перенесите APK на Android-телефон и откройте его. Разрешите приложению доступ к камере — Android использует это разрешение для управления вспышкой.

## Голос

Приложение использует русский голос, установленный в настройках Android «Синтез речи». Немного повышены высота и скорость речи для более молодого звучания. Точный тембр зависит от установленного голосового движка и выбранного голоса.

При уходе приложения с экрана фонарик автоматически выключается.


## Облачная сборка через GitHub (без Android Studio)

1. Создайте новый пустой репозиторий на https://github.com.
2. Загрузите в него все файлы этого проекта (включая скрытую папку `.github/workflows`).
3. Откройте вкладку **Actions** в репозитории и выберите workflow **Build Android APK**.
4. Нажмите **Run workflow** (или дождитесь автоматического запуска после загрузки в ветку `main`).
5. Когда сборка завершится успешно, откройте запуск workflow и скачайте артефакт **Fonar-debug-apk** внизу страницы.
6. Распакуйте скачанный артефакт — внутри будет `app-debug.apk`.

Примечание: GitHub может попросить включить Actions для нового репозитория. Сборка выполняется на серверах GitHub; аккаунт GitHub нужен.
